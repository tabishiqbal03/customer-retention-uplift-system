# CV wording by role

Use **Customer Retention Uplift & Decision Intelligence System — synthetic portfolio project**.
The stacks below name implemented technologies; they do not imply production deployment.

## Data Science

Stack: Python, PySpark, NumPy, scikit-learn, SciPy, Matplotlib, PyArrow, pytest.

- Built a randomized synthetic retention experiment with 25,000 customers and 1,280,055 transactions; compared control-only churn and T/S uplift models using validation-only selection and held-out policy evaluation.
- Evaluated frozen budget-constrained targeting on 10,000 new simulated customers using IPW and paired bootstrap intervals; retained an inconclusive/no-rollout recommendation when the primary net-value interval included zero.

## Applied AI Engineering

Stack: Python, FastAPI, Pydantic, HTTPX, Uvicorn, local Ollama/qwen2.5:3b, HTML/CSS/JavaScript, pytest.

- Built a local evidence explanation API/UI with typed report projections, field-level provenance, authoritative numeric rendering and application-controlled uncertainty statements.
- Constrained optional Ollama output to approved explanation IDs and tested validation, refusals and failures; preserved an incomplete historical benchmark and explicitly distinguished deterministic demonstration from unmeasured revised live performance.

## Analytics / Consulting

Stack: Python, PySpark, NumPy, SciPy, Matplotlib, Markdown/HTML reporting.

- Translated synthetic uplift estimates into seven illustrative contribution/cost scenarios, budget and contact constraints, and a stakeholder decision brief.
- Communicated the difference between predicted value and uncertain randomized-outcome estimates; designed an 8,258-customer hypothetical pilot for offer efficacy within the target population.

Do not claim realised revenue, deployed banking impact, an improved live LLM success rate, or whole-policy superiority. The historical basic model passed 11/28 supported cases; the bound run completed only five (two passed). The current optional-only contract remains live-unmeasured. Deterministic mode is explicitly selected, not an automatic fallback after model failure. See the [final audit](../reports/final-portfolio-audit.md).
